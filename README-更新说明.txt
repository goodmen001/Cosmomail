Cosmo Mail v1.3.0 增量更新包（相对 v1.2.1）
=============================================

本次更新内容：
1. 多用户模式：支持注册、管理员用户管理、注册开关，每个用户数据完全隔离
2. 多邮箱并发连通修复（SQLite 写入争用缓解）
3. 新增服务商预设「阿里企业邮」（IMAP 993 / POP3 995 / SMTP 465，均 SSL）
4. 联系人功能：发信收件人自动记录去重，写信时可直接选择
5. 自定义数据目录：fnOS 向导可填写自定义目录；通用环境变量 COSMOMAIL_DATA_DIR
6. 支持修改登录密码

使用方式：
- 将本包内的文件按原目录结构覆盖到源码根目录，
  然后重新构建（server: go build；web: pnpm build），或直接使用完整包。

完整包请下载：Cosmomail-v1.3.0-完整包.zip
